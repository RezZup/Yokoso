# Shader reference snippets

These small GLSL files (`rain_streaks`, `sakura_particles`, `volumetric_fog`, `optimizations`) are standalone reference snippets. `index.html` does not load them: the shaders the site actually runs are defined inline in the page script.

Use them as starting points for experiments, not as a description of the live scene. For what the scene really contains, see [`docs/PROCEDURAL_3D_WORLD_GUIDE.md`](../../docs/PROCEDURAL_3D_WORLD_GUIDE.md).
